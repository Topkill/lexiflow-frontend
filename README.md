# LexiFlow Frontend

LexiFlow 前端是一个基于 Vue3 的 AI 背单词 Web 应用，覆盖普通用户学习端和管理员运营后台。用户端强调清爽、高效、响应式的背单词体验；管理端采用 Element Plus 后台布局，支撑词库、单词、用户、AI 配置和导入任务管理。

## 技术栈

- Vue3
- Vue Router
- Pinia
- Axios
- Element Plus
- Vite

## 本地环境

请先启动后端服务：`http://localhost:8080`。

前端开发环境已配置 `/api` 代理到后端，所以页面接口统一通过 `/api/v1/**` 访问。

## 启动方式

在 PowerShell 中进入前端仓库目录：

```powershell
cd C:\Users\delll\Desktop\java项目\ai专用\背单词项目\frontend\lexiflow-frontend
npm install
npm run dev
```

默认开发地址：`http://localhost:5173`。

## 构建验证

```powershell
npm run build
```

构建已配置 Vue、Element Plus、图标和公共依赖拆包，便于控制首屏资源体积和演示输出噪音。

## 推荐演示链路

普通用户：

1. 登录或注册。
2. 在词库页选择 CET4、CET6 或考研英语。
3. 创建每日新词学习计划。
4. 回到首页开始今日任务。
5. 在学习卡片中反馈“不认识 / 认识”。
6. 完成一组后生成 AI 完形填空并提交答案。
7. 查看错词、收藏、统计和学习报告。
8. 在私有 AI 配置页切换自己的 OpenAI 兼容接口。

管理员：

1. 登录管理员账号进入后台。
2. 查看数据看板。
3. 管理用户状态。
4. 新增或编辑词库和单词。
5. 下载 Excel 模板并导入单词。
6. 配置公共 AI 服务并设置每日配额。
7. 查看 AI 调用日志和失败原因。
8. 维护系统配置。

## 交互说明

- 新用户没有学习计划时，页面会展示创建计划引导，不把“学习计划不存在”作为错误弹窗打扰用户。
- 背完一组新词和复习词后，系统会引导生成包含本组单词的 10 空 AI 完形填空。
- 用户点击“不认识”后会继续复现该词，直到确认想起来。
- 公共 AI 配置和用户私有 AI 配置都支持 OpenAI 兼容接口。
- 页面适配 PC 和移动端 Web，移动端导航提供常用用户入口。

## 作品集亮点

- 用户端和管理端都已形成闭环，不是静态页面演示。
- AI 能力覆盖讲解、例句、记忆法、完形填空和学习报告。
